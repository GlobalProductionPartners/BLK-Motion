# Kinetic Lights Software Brief

## Overview
Motion Control software is a real-time control platform for synchronized kinetic lighting systems. It is used to program, preview, and run complex motion and lighting shows across multiple winches and fixtures.

## Purpose
The software should help users:
- Create and edit complex show sequences
- Control winches and lighting fixtures in real time
- Preview installations before arriving on site
- Support both creative programming and practical live operation

## Core Functionality
- Multi-device control for winches and light fixtures
- Show creation with cues, timing, and sequencing
- Built-in library of motion and lighting effects
- Customizable parameters for motion, color, timing, and intensity
- Linking of motion and lighting behaviors
- 3D preview of installation layouts
- Playback support for rehearsals and live events
- control each fixture still through a Artnet passthrough. 

## Operational Features

- Manual and automatic addressing options
- Integration with external systems through Art-Net, and OSC
- Real-time feedback from hardware for monitoring and safety
- Remote control validation for safe operation
- Tools for testing, calibration, and firmware updates
- Network-based discovery and addressing of winches
