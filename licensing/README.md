# BLK Motion Licensing

Hardware-locked licensing with **one-time online activation**. The app contacts
the license server exactly once per machine; it receives an Ed25519-signed
license file bound to that machine's hardware fingerprint and validates it
locally on every launch — **no network needed ever again**, including at shows.

## How it works

```
first run (online, once)                     every later run (offline OK)
┌──────────┐  key + machine fingerprint  ┌──────────┐      ┌──────────┐
│ BLK      │ ──────────────────────────► │ Cloudflare│      │ BLK      │
│ Motion   │                             │ Worker+D1 │      │ Motion   │
│          │ ◄────────────────────────── │ (signs)   │      │ reads    │
└──────────┘   signed license file       └──────────┘      │ local    │
     saves to userData/license.json                        │ file +   │
                                                           │ verifies │
                                                           │ signature│
                                                           └──────────┘
```

- The signature is Ed25519. The **public** key is embedded in the app
  (`src/main/license.js`); the **private** key lives only in the Worker secret.
- The license file records the machine fingerprint (macOS IOPlatformUUID /
  Windows MachineGuid / Linux machine-id, SHA-256 hashed). Copying the file to
  another machine fails verification.
- Seats: a key activates up to `seats` machines (default 1). Reinstalling on
  the same machine re-issues without using a seat. Deactivate (in-app, or the
  admin API) frees a seat.
- Revoking a key (set `status='revoked'` in D1) blocks **future activations**.
  Already-activated machines keep working offline — that is intentional: a
  show machine must never die because it can't phone home.

## Deploying the server (needs the Cloudflare account — ~10 min)

Prereqs: Node installed, then `npm i -g wrangler` and `wrangler login`.

```sh
cd licensing/worker

# 1. Create the database, then paste the printed database_id into wrangler.toml
wrangler d1 create blk-motion-license

# 2. Create the tables
wrangler d1 execute blk-motion-license --remote --file=schema.sql

# 3. Secrets: the signing key (from the repo, gitignored) and an admin password
wrangler secret put LICENSE_SIGNING_KEY < ../signing-key.b64
wrangler secret put ADMIN_TOKEN            # type a long random string, save it somewhere safe

# 4. Ship it — the printed URL (https://blk-motion-license.<acct>.workers.dev)
#    goes into the app: Settings → License → Server, and as the default in
#    src/main/license.js (LICENSE_SERVER)
wrangler deploy
```

> `licensing/signing-key.b64` was generated by
> `node licensing/scripts/generate-keypair.mjs` and is **gitignored** — it must
> travel to the deployer by a secure channel, never through git. Regenerating
> the pair invalidates every issued license.

## Issuing license keys

```sh
curl -X POST https://<worker-url>/admin/keys \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"customer":"Acme Productions","email":"tech@acme.com","seats":2}'
# → {"ok":true,"key":"BLKM-XXXX-XXXX-XXXX-XXXX"}
```

List licenses + seat usage:

```sh
curl https://<worker-url>/admin/licenses -H "Authorization: Bearer <ADMIN_TOKEN>"
```

Free a seat for a customer whose machine died:

```sh
curl -X POST https://<worker-url>/deactivate \
  -H "Content-Type: application/json" \
  -d '{"key":"BLKM-...","machineId":"<from the customer's License panel>"}'
```

## In the app

- **Settings → License**: shows status, machine ID (customers read this to you
  for support), key entry + Activate, and Deactivate (frees the seat online).
- Unactivated **packaged** builds show a blocking activation screen at launch.
  Dev runs (`npm start`) are never blocked.

## Local testing without Cloudflare

`node licensing/scripts/test-server.mjs` runs the identical Worker logic on
http://127.0.0.1:8787 with an in-memory database and a test key it prints on
boot — point Settings → License → Server at it.
`node licensing/scripts/worker-test.mjs` is the offline unit test of the
activate/seat/deactivate/signature logic.
